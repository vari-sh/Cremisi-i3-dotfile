<h3 align="center">
	Cremisi Obsidian Flavor for <a href="https://github.com/sxyazi/yazi">Yazi</a>
</h3>

Dark variant of the Cremisi theme by vari.sh: a gothic, arcane palette built as a reliquary of
materials (crypt stone background, bone text, blood and crimson accents, a single cold lapis note).

## ⚙️ Usage

Copy this folder to `~/.config/yazi/flavors/` and set the content of your `theme.toml` to:

```toml
[flavor]
dark = "cremisi-obsidian"
```

Make sure your `theme.toml` doesn't contain anything other than `[flavor]`, unless you want to override certain styles of this flavor.

`tmtheme.xml` is generated from the Cremisi role -> TextMate scope map and is used for code previews.
